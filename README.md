# 🦊 Renard Malin — Tables de multiplication

Une application ludique pour réviser les tables de multiplication, créée pour Justine.

## Fonctionnalités

- 5 niveaux progressifs, du "Renardeau" au "Grand Maître Renard", couvrant les tables de 1 à 12
- Quiz à choix multiples avec un mascotte renard qui réagit aux réponses
- Étoiles (1 à 3) par niveau selon le score
- Récompenses à débloquer : badges de niveau, bonus de rapidité, série de jours joués
- Progression sauvegardée automatiquement sur l'appareil (aucun compte requis)
- Installable comme application (PWA) sur tablette ou téléphone

## Développement

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
npm run preview
```

## Déploiement

Le site est déployé automatiquement sur GitHub Pages à chaque push sur `main` via GitHub Actions.
